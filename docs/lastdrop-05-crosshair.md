# lastdrop-05 - 조준점 위치 버그 (오퍼스 실측)

## 무엇을 했나
조준점(#cross)·히트마커(#hit)·E 안내(#prompt)·못 쏘는 이유(#why)·조준경(#scope)을 HUD 그리드 흐름에서 빼
**뷰포트 정중앙 기준 `position:fixed`** 로 고정했다. 저격 조준경에 중앙 십자선을 넣고, 배율 중엔 일반 조준점을 숨긴다.

## 변경 파일 목록
- `lastdrop/index.html` — CSS (fixed 고정, 조준경 십자선, 재발 방지 주석)
- `lastdrop/game.js` — `crossEl` 참조, 저격 배율 중 조준점 숨김 (2줄)
- `docs/lastdrop-05-crosshair.md`

## 원인 → 수정

| 원인 | 수정 |
|---|---|
| `#cross`·`#hit` 이 `#mid`(HUD 그리드 `auto 1fr auto` 의 가운데 행) 안에서 가운데 정렬 → 위 행(생존·자기장·킬피드)과 아래 행(HP·미니맵·총) 높이 차만큼 위로. 킬피드가 늘면 다시 움직임 | `#cross{position:fixed;left:50%;top:50%;width:0;height:0}` — 0×0 상자라 중심이 정확히 한 점. `#hit` 도 fixed 중앙 |
| `#prompt`·`#why` 도 `#mid` 기준 오프셋 | fixed, `top:calc(50% + 40px)` · `calc(50% + 74px)` (뷰포트 중앙 기준) |
| 저격 조준경에 십자선 없음 | `#scope` fixed + `::before`(가로)·`::after`(세로) 2px 선, 중앙에 걸치게 margin -1px. 배율 중 `#cross` 는 `visibility:hidden` |
| 재발 | CSS 주석: 조준점은 반드시 뷰포트 고정. `#hud` 와 그 조상에 transform·filter·backdrop-filter·contain 금지(fixed 기준이 바뀐다). 자식(.pan)에 거는 건 괜찮다 |

총알은 원래부터 카메라 정중앙(= 캔버스 #gl 중앙 = 뷰포트 중앙)으로 나갔다. 바뀐 건 **화면에 그려지는 조준점 위치**뿐이다.

### 2. 조준점 위 표적 실사격
조준점 **픽셀**을 지나는 카메라 광선 위 d m 에 표적 가슴(1.2m)을 두고 실제 `myShoot()` 으로 쏜다. 공중(80m)에서 재 지형 영향 없음.
"탄착 높이" = 반동 전 총알 방향이 표적 거리에서 조준점보다 몇 m 위(+)/아래(−)로 지나나.

| 화면 | 사격 | 수정 전 명중 · 탄착 높이 | 수정 후 명중 · 탄착 높이 |
|---|---|---|---|
| 1920×1080 | 퍼짐 0, 소총 50m | 0% · −3.38m | **100% · 0** |
| 1920×1080 | 퍼짐 0, 소총 100m | 0% · **−6.75m** | **100% · 0** |
| 1920×1080 | 퍼짐 0, 소총 200m | 0% · −13.51m | **100% · 0** |
| 1920×1080 | 정조준 소총 50m (300발) | 0% · −2.19m | **100%** · 0 |
| 1920×1080 | 정조준 소총 100m (300발) | 0% · −4.38m | **92%** · 0 (실제 퍼짐) |
| 1920×1080 | 정조준 저격 200m (300발) | 0% · −3.17m | **100%** · 0 |
| 1280×720 | 퍼짐 0, 소총 50 / 100 / 200m | 0% · −5.05 / −10.1 / −20.2m | **100% · 0** |
| 1280×720 | 정조준 소총 50 / 100m · 저격 200m | 0% / 0% / 0% | **100% / 96% / 100%** · 0 |

- 오퍼스 계산(100m 에서 약 6.7m 아래)과 일치: 1080p −6.75m. 720p 는 같은 48px 이 화면 비율로 더 커서 −10.1m.
- 정조준(배율)에서 수정 전 오차가 작은 건 화각이 좁아(소총 52°, 저격 20°) 같은 픽셀 차가 작은 각도라서다.

### 3. 기타
- 저격 배율: `#cross` visibility hidden, `#scope` 십자선 교차점 = 화면 중앙(1280×720 스크린샷 640,360).
- 봇전 1판 완주, 런타임 오류 0.
