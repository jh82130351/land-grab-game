# 07 - 봇 자멸 버그 수정 + AI 개선

## 무엇을 했나
- **"봇이 잡히지도 않았는데 사라진다"** 의 원인을 찾아 고쳤다. 자기 궤적을 밟은 자멸이었다.
- 봇 AI를 자유각 주행에서 **격자 주행**으로 바꾸고, 확장 방향 선택과 **사냥(궤적 자르기)** 을 넣었다.
- **킬로그**를 추가해 누가 왜 죽었는지 화면에 남긴다.

---

## 1. 봇이 사라지던 원인

봇이 자유 각도(`heading`)로 움직이다 보니 **자기가 방금 그린 궤적 위로 되돌아 들어갔다.**
규칙상 궤적을 밟으면 그 주인이 죽으므로, 아무도 안 건드렸는데 봇이 혼자 사라진다.
사망 시 영토가 리셋되므로 점유율도 시작값으로 돌아간다.

수정 전 3분 시뮬레이션 로그 (봇이 계속 0.06% = 시작 영역으로 리셋된다):
```
[t60s]  봇A 0.06% · 봇B 0.06% · 봇C 2.78%
[t150s] 봇A 0.06% · 봇B 4.22% · 봇C 3.15%
```

### 고친 방법 — 격자 주행
봇이 **한 칸씩** 이동하게 바꿨다. 다음에 들어갈 칸이 정해져 있으니
`trail[다음칸] === 내 id` 를 확실히 검사해서 **자기 궤적 칸은 아예 후보에서 뺀다.**
자유 각도에서는 "두 칸 앞 검사" 같은 어림짐작밖에 못 했는데, 이제는 확정적이다.

추가로 사각형이 닫히도록 **1번 변과 3번 변 길이를 같게** 유지한다 (06단계에서 시작한 수정).

**결과: 3분 경기 3판에서 자멸 0회.** 발생한 사망은 전부 정당한 것이었다.
```
[사망] 봇 C — 나에게 잡힘      ← 플레이어가 봇 궤적을 밟아 자른 것
```

## 2. AI 개선

| 개선 | 내용 |
| --- | --- |
| **확장 방향 선택** | 네 방향으로 24칸씩 훑어 **내 땅이 아닌 칸이 가장 많은 쪽**으로 나간다. 전에는 무작위라 자기 영토 한가운데로 걸어들어가 시간을 버렸다. 벽 쪽은 감점. |
| **사냥** | 15칸 안에 남의 궤적이 있으면 **끊으러 간다.** 내 궤적이 110칸 미만일 때만 (욕심부리다 죽지 않게). 목표 궤적이 사라지면 즉시 귀가로 전환. |
| **과욕 방지** | 궤적이 220칸을 넘으면 무조건 귀가. |
| **집 재탐색** | 영토를 빼앗겨 집이 사라지면 가장 가까운 내 땅을 다시 찾는다 (드물게만 실행). |
| **사각형 크기** | 한 변 10~32칸(15~48m)으로 키웠다. |

**결과: 봇 점유율이 2~5% 대에서 5~10% 대로 올라갔다.** 3분 경기 3판:
```
판1  봇A 8.30% · 봇B 5.96% · 봇C 7.76%   (사망 0)
판2  봇A 10.66% · 봇B 5.85% · 봇C 3.46%  (봇C 1회 — 플레이어에게 잡힘)
판3  봇A 7.27% · 봇B 5.11% · 봇C 4.90%   (봇C 2회 — 플레이어에게 잡힘)
```

## 3. 킬로그
미니맵 아래에 사망 사유가 뜬다. 최근 4건, 6초 후 사라진다.
```
봇 A — 봇 C에게 포위당함
봇 B — 나에게 잡힘
```
사유는 세 가지다. `자기 궤적에 걸림` / `OOO에게 잡힘` / `OOO에게 포위당함`.
**원인이 안 보이면 정상 동작도 버그로 보인다**는 게 이번 지적의 핵심이라 판단해 넣었다.

## 알려진 버그 · 미완
1. **봇끼리는 잘 안 만난다.** 사냥 반경이 15칸(22m)이라 넓은 맵에서 마주칠 일이 적다.
   경기가 조용하면 반경을 늘리거나 봇을 서로 가깝게 배치해야 한다.
2. **봇이 도망치지 않는다.** 자기 궤적이 길 때 적이 접근해도 회피 기동을 안 한다.
3. 점유율이 여전히 10% 안팎이라 60% 즉시 종료는 발동하지 않는다 (06 문서 지적 그대로).
4. 사망 페널티(전부 잃음)와 맵 크기·시간은 06 문서의 확인 요청 그대로 남아 있다.

   체감이 중요하다. 봇을 더 공격적으로 만들지, 더 크게 먹게 만들지 방향을 주시면 그쪽으로 맞추겠다.
