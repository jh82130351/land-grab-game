# lastdrop-02 - 버그 수정 일괄 (오퍼스 코드 검토 + 헤드리스 실측)

## 무엇을 했나
오퍼스 검토 12개 항목(높음 4 · 중간 4 · 낮음 4)을 고치고 13번은 기록만 했다. 난이도 표(`TIERS`)와 맵 크기는 손대지 않았다.
각 항목을 **수정 전 사본(bdf36e2)과 수정 후를 같은 헤드리스 하네스로** 재서 아래 표에 나란히 적었다.

> 참고: 이 지시서는 난이도 작업(bdf36e2, lastdrop-01) 이전 코드를 기준으로 쓰인 것으로 보인다.
> 3번(봇 조준 높이)·11번 결과화면 "12명 중"·13번 일부(구급상자)는 lastdrop-01 에서 이미 반영돼 있었다 — 아래에 표시.

### 표 1 — 내 사격: 조준한 부위에 맞은 비율 (수정 전 → 후)
소총 · 지향사격(퍼짐 bloom 0) · 서 있는 표적 · 칸마다 300발 · 카메라에서 조준점으로 겨눔

| 내 자세 | 거리 | 머리 | 가슴 | 다리 |
|---|---|---|---|---|
| 서기 | 3m | 18% → **100%** | 100% → **100%** | 100% → **100%** |
| 서기 | 8m | 38% → **100%** | 100% → **100%** | 100% → **100%** |
| 서기 | 20m | 40% → **51%** | 91% → **100%** | 100% → **100%** |
| 서기 | 50m | 10% → **8%** | 32% → **32%** | 49% → **42%** |
| 앉기 | 3m | 0% → **100%** | 0% → **100%** | 80% → **100%** |
| 앉기 | 8m | 0% → **100%** | 31% → **100%** | 100% → **100%** |
| 앉기 | 20m | 0% → **97%** | 39% → **100%** | 81% → **100%** |
| 앉기 | 50m | 13% → **22%** | 42% → **89%** | 56% → **86%** |
| 엎드리기 | 3m | 0% → **100%** | 0% → **100%** | 0% → **100%** |
| 엎드리기 | 8m | 0% → **100%** | 0% → **100%** | 0% → **100%** |
| 엎드리기 | 20m | 0% → **100%** | 0% → **100%** | 0% → **100%** |
| 엎드리기 | 50m | 0% → **60%** | 0% → **100%** | 0% → **20%** |

- 20m 안은 자세와 무관하게 조준한 곳에 맞는다(서서 20m 머리 51% 만 예외 — 지향사격 퍼짐이 머리 폭보다 크다).
- 50m 빗나감은 지향사격 퍼짐 때문(앉기 ×0.62·엎드리기 ×0.38 이라 낮을수록 잘 맞는다). 엎드려 50m 다리 20% 는 낮은 사선이 지형 굴곡에 걸린다.
- 수정 전 서서 3m 머리 18% — 총구(1.52m)가 눈(1.68m)보다 0.16m 낮아 조준점 아래로 나갔다.

## 감독 확인 요청 사항 / 남은 이슈
- **실브라우저 확인 필요(정현)**: 실제 마우스로 앉기·엎드려 쏘기 체감, ESC → 오버레이 → 클릭 재개, 자기장 밖 소리. 헤드리스는 포인터 락·소리 재생을 못 한다.
- 5번 샷건 해석: "기존 감쇠 유지" + "유효 25m" → 감쇠 공식 모양은 그대로(유효 안 1→0.4, 넘으면 0.35×유효 안에 0), 기준 거리만 18→25m.
- 5번에서 `g.range` 는 그대로 — 봇의 교전 거리·사격 개시 거리에 쓰여서 바꾸면 난이도가 바뀐다. 난이도 작업에서 함께 정할 것.
- 12번 미니맵은 거리 제한 없이 3초 안에 쏜 적 전부 — 너무 많이 보이면 청음 거리(예: 150m)를 더하자.
- 경기 시간은 여전히 5.5분 남짓(자기장 합 288초, lastdrop-01 4절) — 다음 작업(맵 크기)과 함께.
- 13번 기록 사항은 그대로 남아 있다.
