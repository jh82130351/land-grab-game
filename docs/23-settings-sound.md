# 23 - 설정 메뉴 + 사운드

## 무엇을 했나
설정 화면에서 소리 크기를 조절하고, 게임의 주요 사건마다 효과음이 나고, 경기 중에 배경음이 돈다.
**소리는 전부 Web Audio로 그 자리에서 만들어 낸다. 받아오는 음원 파일이 0건이다** — 저작권
문제도 없고 로딩도 없다.

---

## 1. 설정 UI

- **시작 화면**과 **일시정지 화면** 양쪽에 `설정` 버튼을 넣었다.
- 항목: **전체 / 효과음 / 배경음** 슬라이더(0~100)와 **음소거** 토글.
- 슬라이더를 끄는 즉시 게인에 반영된다. 놓는 순간 지금 크기를 **귀로 확인**시켜 준다
  (효과음은 짧은 음, 배경음은 0.9초 미리듣기).
- `ESC`는 설정이 떠 있으면 설정부터 닫는다. 설정이 떠 있는 동안에는 화면 클릭으로
  포인터가 잠기지 않는다.
- **값은 이번 접속 동안만 유지된다.** 저장은 지시대로 넣지 않았다.

| 항목 | 기본값 |
| --- | --- |
| 전체 | 70 |
| 효과음 | 80 |
| 배경음 | 35 |
| 음소거 | 꺼짐 |

## 2. 소리 구조

```
오실레이터 · 잡음 ─┬─▶ sfxBus ─┐
                  └─▶ bgmBus ─┴─▶ master ─▶ 스피커
```
- **전체** 슬라이더는 `master`, **효과음**은 `sfxBus`, **배경음**은 `bgmBus`를 움직인다.
- **음소거**는 `master`를 0으로 내린다. 풀면 원래 값으로 돌아온다.

### 자동재생 정책
브라우저는 사용자가 한 번 누르기 전에는 소리를 못 내게 막는다. 그래서
**`AudioContext`를 페이지 로드 때 만들지 않고, 첫 클릭에 만든다.**
```js
addEventListener('pointerdown', (e) => {
  if (e.target.closest('.btn') || e.target.closest('.tog')) { audioResume(); sndClick(); }
}, true);
```
어떤 버튼을 누르든(시작·참가·설정) 이 길목을 지나므로 그때 깨어난다. 경기 시작에서도 한 번 더 부른다.

### 소리가 안 돼도 게임은 돈다
바깥으로 나가는 모든 길목(`audioInit`·`tone`·`noise`·`bgmStep`·`applyVolume`)을
`try/catch`로 감쌌다. 실패하면 조용히 무음이 되고 게임 로직은 그대로 흐른다.
아래 검증 (5)에서 소리가 막힌 상태로도 경기가 정상 진행되는 걸 확인했다.

## 3. 효과음 (전부 합성)

| 사건 | 소리 |
| --- | --- |
| **점령 성공** | 삼각파 2~3음 상승. **먹은 칸이 많을수록 높고 길다** (300Hz/0.10초 → 560Hz/0.20초) |
| **킬** (상대 궤적 자름) | 사각파 880→180Hz 급하강 + 짧은 잡음 |
| **사망** | 톱니파 300→60Hz + 낮게 깎은 잡음 0.34초 |
| **아이템 획득** | 사인파 660 → 990Hz 두 음 |
| **스킬 사용** | 톱니파 + 배음. **스킬마다 기준 음이 다르다** (부스트 520 · 무적 420 · 확대 620 · 귀환 340Hz) |
| **달리기 시작** | 잡음 0.16초. 걷기 → 달리기로 바뀌는 순간에만 |
| **경고** | 사각파 2음. 내 궤적이 40칸 넘게 드러났고 적이 18칸 안에 붙었을 때 (또는 궤적 260칸 초과) |
| **경기 시작** | 392·523·659Hz 상행 |
| **승리 / 패배** | 4음 상행 / 4음 하행 |
| **버튼 클릭** | 짧은 사각파 |

경고는 **1.8초에 한 번**만 울리고, 궤적 검사는 **0.4초에 한 번**만 돈다 (매 프레임 훑으면 비싸다).

## 4. 배경음
반음 단위 패턴을 계속 돈다. 베이스는 매 박, 리드는 두 박에 한 번.
**남은 시간이 30초 이하로 내려가면 템포가 올라간다.**

| | 한 박 |
| --- | --- |
| 보통 | **0.28초** |
| 막판 (30초 이하) | **0.21초** (25% 빠름) |

렌더 루프는 창이 뒤로 밀리면 느려지므로 **배경음은 90ms짜리 별도 타이머**로 예약한다.
경기 시작에 켜지고 종료·메뉴 복귀에서 꺼진다. 봇전·온라인 공통이다.

## 5. 검증

### (1) 사건마다 소리가 나는가
오실레이터·잡음이 실제로 몇 개 시작됐는지 가로채 셌다.
```
점령 작게(60칸)  오실 2 · 잡음 0     점령 크게(900칸) 오실 3 · 잡음 0   ← 크기에 따라 다르다
킬               오실 1 · 잡음 1     사망             오실 1 · 잡음 1
아이템 획득        오실 2 · 잡음 0     스킬 사용         오실 2 · 잡음 0
달리기 시작        오실 0 · 잡음 1     경고             오실 2 · 잡음 0
경기 시작          오실 3 · 잡음 0     승리 4 · 패배 4 · 버튼 클릭 1
```

### (2) 실제 경기에서도 나는가 (봇전)
경기를 돌리며 누적 소리 수를 찍었다.
```
경기 시작 직후 0 → 아이템 2개 주운 뒤 4 → 스킬 1회 쓴 뒤 6 → 네모 한 바퀴 돌아 점령 뒤 11
내 땅 641칸 · 런타임 오류 0건
```

### (3) 볼륨과 음소거가 즉시 먹는가
| | master | sfx | bgm |
| --- | --- | --- | --- |
| 기본 | 0.70 | 0.80 | 0.35 |
| 효과음 25·배경음 10으로 내린 뒤 | 0.70 | **0.25** | **0.10** |
| 음소거 켬 | **0.00** | — | — |
| 음소거 끔 | **0.70** | — | — |

설정 창 열기·닫기, 슬라이더가 현재 값(70/80/35)을 그대로 보여 주는 것도 확인했다.

### (4) 배경음 템포
예약된 음 사이 간격을 직접 쟀다.
```
보통(남은 120초) : 한 박 0.28초
막판(남은  20초) : 한 박 0.21초
```

### (5) 자동재생 정책 · 소리가 막혀도 게임이 도는가
**자동재생 허용 플래그 없이** 돌렸다.
```
페이지 로드 직후_ctx   아직 안 만듦     ← 로드만으로는 오디오를 건드리지 않는다
설정 버튼 클릭 후_ctx   suspended
경기 시작 후_ctx       suspended
소리 준비됨            True
게임은 도는가          True            ← 소리가 막혀도 경기는 그대로 돈다
오류                 없음
```
> 헤드리스에서 만든 클릭은 브라우저가 **진짜 사용자 조작으로 쳐 주지 않는다.**
> 그래서 `suspended`에서 안 풀린다. **구조(로드 때 안 만든다 · 클릭에 `resume()`을 부른다 ·
> 막혀도 게임은 돈다)는 확인했지만, 실제로 소리가 나는 순간은 실기에서 봐주셔야 한다.**
> 자동재생을 허용한 조건에서는 `running`으로 바뀌고 위 (1)~(4)가 전부 울린다.

## 알려진 이슈
1. **실기에서 첫 클릭에 소리가 나는지는 확인이 필요하다.** 위 검증 (5) 참조.
   헤드리스가 만든 클릭은 브라우저가 사용자 조작으로 안 쳐 준다.
2. **설정 값이 저장되지 않는다.** 새로고침하면 기본값으로 돌아간다. 지시대로 나중 과제다.
3. **상대의 점령·킬 소리는 안 난다.** 내 사건만 울린다. 넷이 동시에 울리면 시끄러워서
   그렇게 뒀는데, 상대 소리도 (작게) 넣을지는 판단 부탁드린다.
4. **배경음이 단순하다.** 8박 패턴 하나를 계속 돈다. 질린다 싶으면 패턴을 늘리면 된다.
5. 14·16·19 문서의 판단 대기 건은 그대로다.
