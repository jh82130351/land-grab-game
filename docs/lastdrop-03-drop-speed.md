# lastdrop-03 - 낙하 속도 통일

## 무엇을 했나
봇도 나와 **같은 낙하 물리**(자유낙하 → 낙하산 → 착지)로 내린다. 착지점까지의 거리로 뛰는 시점을 정하고,
못 닿는 착지점은 닿는 자리로 바꾼다. 낙하 시간을 약 10초로 줄이고 W 다이브·S 활강, HUD 착지 예상 초를 넣었다.

## 변경 파일 목록
- `lastdrop/game.js`
- `lastdrop/index.html` — 조작 안내에 "낙하 중 W / S" 한 줄
- `docs/lastdrop-03-drop-speed.md`

## 원인 → 수정

| # | 원인 | 수정 |
|---|---|---|
| 1 | 봇은 `pt += dt/9` 선형 보간 — 물리 없음, 거리 무관, 늘 9초 | 나와 봇이 같은 `fallStep()` 을 쓴다. 수평 속도도 같다(자유낙하 26, 낙하산 15m/s) |
| 1 | 봇 착지점이 집 중심 ±22m — 벽·지붕 속일 수 있었다 | `landOK()`: 육지(`heightAt ≥ -2`)이고 벽·지붕·바위 발자국(+1m) 밖만. `spotNear()` 로 집 둘레에서 고른다 |
| 1 | 뛰는 시점 `dropT` 가 거리와 무관한 난수 | `planDrops()`: 한 번 낙하로 갈 수 있는 수평거리 `dropReach()` 의 80% 안에 들 때 뛴다 (처음 닿는 때~가장 가까울 때 사이 난수). 못 닿으면 항로에서 가까운 집 12채 둘레 → 그래도 없으면 항로 아래 육지로 바꾼다 (**고른 자리 자체로** 도달 판정) |
| 2 | 나: 최대 58m/s, 115m 에서 낙하산 -8.5m/s (이 구간만 13초) — 약 18초 | `FALL` 표 하나: 가속 42, 최대 65, `CHUTE_Y` 70, 낙하산 -14. W 다이브(최대 80, 앞으로 14m/s) · S 활강(최대 45, 앞으로 34m/s) · A/D 옆 26m/s. 더 빠른 상태에서 느린 상태로 바뀌면 30m/s² 로 줄인다(급정거 없음) |
| 3 | HUD 는 고도만 | `고도 Nm · 착지 N초` — `etaLand()` 가 기본 자세 물리로 계산 |

> 해석 메모: 지시서의 "S = 활강(느림·수평 멀리)" 를 **앞으로** 멀리 가는 것으로 했다(뒤가 아니라). 자유낙하 중 W/S 는 이동이 아니라 자세다.
> 낙하산은 예전처럼 WASD 로 15m/s.

## 검증 (헤드리스, frame() 50ms 스텝)

### 같은 지점·같은 순간에 뛴 나와 봇 (3판)
| 판 | 나 | 봇 (바로 아래) | 봇 (수평 72m 이동) |
|---|---|---|---|
| 1 | 10.30초 | 10.25초 | 10.15초 |
| 2 | 10.05초 | 10.00초 | 10.15초 |
| 3 | 9.65초 | 9.60초 | 9.45초 |

차이 **0.05~0.20초** (목표 1초 이내). 72m 이동 봇은 착지점 고도가 달라 조금 다르다. 착지점 오차 0.2~1.1m.

### 비행기 출발 직후(plane.t 0.003) 뛰었을 때 착지까지
| 키 | 착지 |
|---|---|
| 없음 | **10.05초** (목표 약 10초 · 수정 전 약 18초) |
| W 다이브 | 8.95초 |
| S 활강 | 11.65초 |

HUD 예상: 뛴 직후 "착지 11초" → 2초 뒤 9초 → 4초 뒤 7초 … 실제 10.15초 (올림이라 최대 1초 크게 보인다).

### 봇 15기 전원 착지 (40판 = 600기, 착지한 그 순간 기록)
| 항목 | 결과 |
|---|---|
| 착지 성공 | **600 / 600** |
| 바다 | **0** |
| 벽 속 | **0** |
| 지붕 위 | 0 |
| 계획한 착지점과 오차 | 최대 0m |
| 봇 낙하 시간 | 9.2~10.1초 (수정 전 9초 고정 · 거리 무관) |
| 마지막 봇 착지 | 출발 후 26~36.5초 |

- 첫 20판에서 착지점 오차 최대 130m 가 나왔다 → 대체 착지점을 **집 중심** 거리로 판정해 고른 자리가 도달거리 밖일 수 있었다. 고른 자리로 판정하게 고친 뒤 40판 오차 0.
- (측정 메모) 판 끝에 위치를 재면 '바다'가 나오는데, 착지 뒤 drop 단계에서 걸어 다닌 결과다 — 착지 순간 기준으로 0.

### 봇전 3판
286~345초 완주, 런타임 오류 0.

## 감독 확인 요청 사항 / 남은 이슈
- 실브라우저 체감(정현): 10초 낙하의 속도감, W 다이브·S 활강 느낌, 낙하산이 70m 에서 펴지는 타이밍.
- 다이브는 낙하산 고도가 고정(70m)이라 1초만 빨라진다. 더 차이를 원하면 diveV 를 올리거나 다이브 중엔 낙하산을 늦게(예: 50m) 펴는 방법이 있다.
- 봇은 낙하 중 다이브·활강을 안 쓴다 (기본 자세 + 착지점으로 수평 이동). 도달 거리 계산도 기본 자세 기준.
- 마지막 봇이 출발 후 최대 36.5초에 내리므로 live(자기장 시작)도 그때부터다.
