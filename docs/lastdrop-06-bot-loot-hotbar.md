# lastdrop-06 - 봇 파밍 + 인벤토리 핫바

## 무엇을 했나
봇도 나처럼 **맨손(붕대 2)으로 내려 주워서 싸운다** — 같은 `takeItem` 으로 줍고(탄 종류·가방 용량 같은 규칙), 주운 건 맵에서 사라지고,
탄은 가방에서 소모한다(무한 탄 제거). 집 안 전리품은 **문으로 드나드는 웨이포인트**로 간다. 나·봇 공통 **주먹**.
총은 **핫바 5칸 + 가방(무게 0, 개수 제한 없음)**, 핫바엔 회복템 바로가기도 꽂는다. Tab 화면은 끌어 놓기(pointer 이벤트)·우클릭 메뉴.

| 근처에 없을 때 | 총이 없으면 8m 넘는 회복템·방어구보다 **아직 안 가 본 가까운 집을 뒤지러** 간다 (뛰어서) |

| 총 없을 때 적을 보면 | 어려움 이상: 무장한 적이면 엄폐(없으면 반대로 12m) 후 6초는 계속 파밍. 약간 어려움 이하: 계속 줍기 |
| 주먹 | 맨손 봇은 **3초 안에 나를 때린 상대에게만** 반격 (최소 대응). 처음엔 "붙으면 누구나 + 보통·약간 어려움은 6m 안이면 덤빔" 이었는데, 맨손 봇끼리 전리품 앞에서 만나 주먹 싸움으로 판당 4~6기가 착지 30초 안에 죽어 바꿨다 |
| 무장 후 사격 | 기존 난이도 교전 그대로 (lastdrop-01) |

### 집 안 전리품 경로 (`pathTo` · `routeSeg` · `nav`)
- 문 = 앞(+z) 벽 가운데 폭 2.4m — `houses[]` 의 x·z·w·d 로 `(h.x, h.z + h.d/2)`.
- 밖 → 안: **문 앞 2m → 문 중앙 → 안쪽 1.2m → 전리품**.
- 안 → 밖: **안쪽 → 문 중앙 → 문 앞 2m**.
- 그 사이 집 밖 구간이 어느 집이든(나온 집·들어갈 집 포함) 관통하면 그 집 둘레 2m 모서리로 돌아간다 — 선분·사각형 교차(Liang–Barsky)로
  가장 가까운 집부터 나누고, 나뉜 구간도 다시 검사(재귀, 깊이 6). 벽·문간에 붙어 서 있으면 먼저 가장 가까운 변 바깥으로 1.2m 빠진다.
- 배회(자기장 쪽 이동)도 같은 경로를 쓴다.
- 목표가 바뀌거나, 길을 만들 때와 다른 집 안에 들어와 있으면 다시 만든다. 집에서 나서는 순간엔 다시 만들지 않는다.
- 경로 단위 검사: 봇이 설 수 있는 자리(벽선 0.7m 밖)끼리 무작위 10,000쌍 — **집을 관통하는 경로 0**.
- **포기**: 같은 목표에 8초 안에 못 닿으면 그 봇에겐 '포기' 표시, 다음 후보로.
- **2층**: 2층 바닥은 그림만 있고 충돌판이 없다. 전리품은 `h.base + 0.35`(1층)에만 깔린다 — 확인함, 변경 없음.

## 3. 주먹 (나·봇 공통)
사거리 1.6m · 피해 12 · 0.5초 간격. 내가 맨손이면(핫바 빈 칸·총 없음) 좌클릭이 주먹. HUD `맨손 (주먹)`.

## 4. 인벤토리 핫바

| 조작 | 동작 |
|---|---|
| 1~5 | 핫바 칸 — 총이면 손에, 회복템 바로가기면 바로 사용(손은 그대로), 빈 칸이면 맨손 |
| 휠 | 총이 든 칸만 순환 |
| E / 주변 클릭 | 즉시 줍기 — 총은 빈 핫바 칸, 꽉 찼으면 가방. 맨손이었으면 바로 든다 |
| 주변 → 핫바 칸으로 끌기 | 그 칸에 바로 꽂기 (원래 있던 총은 가방으로) |
| 가방 → 핫바 끌기 / 핫바 → 가방 / 핫바끼리 | 옮기기·자리 바꾸기. "주변" 칸으로 끌면 바닥에 버리기 |
| 우클릭 | 주변: 핫바 1~5번에 넣기 · 가방에 넣기 / 가방 총: 핫바 N번 · 버리기 / 가방 회복템: 핫바 N번 · 전부·절반 버리기 / 가방 탄: 전부·절반 버리기 / 핫바: 가방에 넣기 · 버리기 |
| 가방 총 클릭 | 빈 핫바 칸(없으면 손에 든 칸)에 넣기 |

- 탄·방어구는 핫바에 못 꽂는다("핫바엔 총·회복템만 꽂는다").
- 회복템 바로가기는 그 회복템이 다 떨어지면 칸이 비워진다.
- **lastdrop-04 와 달라진 점**: 총 칸 제한(주무기 2 + 권총)과 "꽉 차면 들던 총이 바닥에" 가 없어졌다 — 총은 무제한(가방). 단축키 3 = 권총 → 1~5 = 핫바.
- UI 는 `createElement`/`textContent`. 끄는 동안엔 목록을 다시 그리지 않는다.
- 봇 상자: 그 봇의 모든 총(장전 탄째)·가방 탄·회복템·헬멧·방탄복·가방 (봇이 주운 방어구가 맵에서 사라지지 않게 상자에 넣는다 — lastdrop-04 에선 총·탄·회복템만이었다).

"문 앞 끼임" = 전리품·집 목표가 있고 주먹 싸움·줍기·치료 중이 아닌데, 문 3m 안에서 3초 동안 0.3m 도 못 움직임.
경기 끝까지(320초) 추적한 3판 중 1판에서 1건 잡혔는데, 잡힌 직후부터는 정상 이동했다(3초 넘게 선 원인은 확정 못 함).

**끼임을 없앤 과정** — 처음엔 판당 최대 17건이었다:
1. 맨손 봇끼리 문에서 마주쳐 주먹 싸움 → 판정에서 제외 + 주먹을 반격 전용으로.
2. 집에서 나와 뒤쪽 목표로 갈 때 나온 집을 관통하는 직선 → 모서리 웨이포인트.
3. 경로를 만든 뒤 집 안팎이 바뀜 → `nav` 재계산.
4. 자기장 밖 봇의 배회 경로가 집 밖에선 직선이라 문을 들락날락 → 모든 이동을 같은 경로(`routeSeg`)로, 관통 검사를 재귀로.

## 6. 한 판 8~12분 — 못 맞췄다
봇전 3판 231~266초(약 4분). 자기장을 늘린 시뮬레이션(게임에는 적용 안 함):

| 자기장 대기·수축 배수 | 경기 시간 (3판) |
|---|---|
| ×1.0 (지금) | 231 · 248 · 266초 |
| ×1.8 | 350 · 360 · 421초 |
| ×2.2 | 398 · 415 · 448초 |

(×1.8·×2.2 줄은 경로 개선 전 빌드에서 잰 값이다.) ×2.2 에서도 6.6~7.5분 — 이젠 자기장보다 **봇끼리 교전으로 먼저 끝난다**. 8~12분은 자기장 연장 + 맵 크기(다음 작업) + 교전 치명도(봇 탐지 거리·명중)를 함께 정해야 한다.

## 감독 확인 요청 사항 / 남은 이슈
- **경기 시간 8~12분 미달** — 위 6절. 자기장 배수와 맵 크기를 함께 결정해 달라.
- 교전 기준 "탄 30발" 을 샷건·저격은 탄창 3개분(15발)으로 낮췄다 — 12게이지 30발은 무게 37.5 라 봇이 거의 못 모은다.
- 보통·약간 어려움의 "맨손일 때 적을 보면" 은 지시서에 없어 쉬움처럼 "계속 줍기" 로 했다(처음엔 6m 안이면 덤비게 했다가 주먹 사망이 많아 뺐다).
- 포기는 판당 0~6회. 다른 봇이 먼저 주운 경우는 포기로 세지 않는다(바로 다음 후보로). 포기의 원인별 분석은 하지 않았다 — 경로는 집만 피하고 나무·바위는 기존 우회(옆으로 비키기)에 맡긴다.
- 실브라우저(정현): 드래그 손맛, 휠 순환, 맨손 주먹 체감.
