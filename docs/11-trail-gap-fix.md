# 11 - 게스트 궤적이 끊기던 버그 수정 (칸 잇기)

## 증상 (정현 보고)
> 게스트는 경로가 안 만들어지고 그런 버그가 있는 거 같은데

## 원인 — 위치 보고 사이의 칸을 건너뛴다
온라인 판정은 이렇게 돈다.
```
게스트 ──(18Hz) 내 위치──▶ 방장 ──▶ 그 위치의 '칸' 하나만 궤적으로 기록
```
방장은 **보고받은 좌표가 속한 칸 하나만** 처리했다. 보고가 촘촘하면 문제가 없지만,
네트워크 지연·프레임 저하로 보고 간격이 벌어지면 **그 사이 칸들이 통째로 빠진다.**
궤적에 구멍이 생기면 폐곡선이 닫히지 않고, 점령 판정(flood-fill)이 그 구멍으로 새어나가
**점령이 통째로 실패한다.** 방장 자신은 매 프레임 판정하므로 멀쩡하고, **게스트만 증상이 난다.**
정현님이 본 "게스트는 경로가 안 만들어진다"가 이것이다.

### 실측 재현
게스트의 위치 전송 주기를 400ms로 늘려(지연이 큰 상황과 같은 효과) 둘이 **똑같이 150m 직진**:
```
방장   : 궤적 98칸   ← 정상 (150m ÷ 1.5m = 100칸)
게스트 : 궤적 59칸   ← 40%가 비어 있음
```

## 고친 내용 — 마지막 칸에서 새 칸까지 메운다
```js
function stepCells(ent, gx, gz) {
  // 마지막으로 있던 칸에서 새 칸까지 상하좌우로 한 칸씩 이어가며 전부 판정한다
  while (cx !== gx || cz !== gz) {
    if (Math.abs(gx - cx) >= Math.abs(gz - cz)) cx += Math.sign(gx - cx);
    else cz += Math.sign(gz - cz);
    stepCell(ent, cx, cz);
    if (!ent.alive) return;     // 중간 칸에서 죽으면 거기서 멈춘다
  }
}
```
- 사이 칸을 **빠짐없이** 지나므로 궤적이 항상 이어진다.
- 중간 칸에서 남의 궤적을 밟으면 **거기서 제대로 죽는다.** 전에는 그 칸을 건너뛰어
  상대 궤적을 그냥 통과해버리는 일도 있었다 (같은 원인의 숨은 버그).
- **순간이동은 잇지 않는다.** 64칸 넘게 벌어지면(리스폰 등) 선을 긋지 않고 그대로 옮긴다.
- 방장 자신에게도 적용했다. 프레임이 떨어지면 방장도 같은 문제를 겪는다.

## 검증 (같은 400ms 조건, 실서버·실터널)
```
수정 전 : 방장 98칸 / 게스트 59칸
수정 후 : 방장 98칸 / 게스트 97칸        ← 구멍 사라짐
```
원을 그려 점령까지 확인:
```
[21s] 방장 영역 410칸 / 게스트 영역  25칸 (아직 주행 중)
[28s] 방장 영역 410칸 / 게스트 영역 410칸  ← 게스트도 정상 점령
      격자합 양쪽 일치
```

## 남은 이슈
1. **상대 캐릭터는 여전히 18Hz로 툭툭 움직인다** (보간 없음). 궤적·점령은 이제 정확하다.
2. 지연이 아주 크면(1초 이상) 상대 위치 표시가 눈에 띄게 늦다. 판정 자체는 이어진다.
3. 09·10 문서의 미완 항목(치팅 방지 없음, 방장 이탈 시 종료, 자동 기동 미적용)은 그대로다.

## 감독 확인 요청
- 다시 2인으로 붙어서 **게스트 쪽 궤적이 끊기지 않는지, 한 바퀴 돌면 점령이 되는지** 확인 부탁드린다.
- 게스트 쪽에서 상대(방장)의 궤적도 제대로 보이는지 같이 봐주시면 좋겠다.
