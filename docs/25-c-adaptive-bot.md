# 25-c - 봇 성향 '학습형' (상황 판단 + 사람 스타일 모방)

## 무엇을 했나
`학습형` 성향에 **A. 상황 판단**을 얹었다. 사람 고수처럼 **"지금 키울 때인가, 조심할 때인가"**
를 읽고 출격 크기·복귀 시점·방향을 바꾼다. **B. 사람 스타일 모방**(어떤 모양으로 돌지)은
앞서 넣은 그대로다. 머신러닝이 아니라 **규칙 + 통계**다.

---

## A. 상황 판단

### 언제 재고 언제 반영하나
- **재는 건** 판단 주기(0.8초)마다. 값은 **EMA(0.35)** 로 천천히 움직인다.
- **반영은 출격을 새로 짤 때(`planBot`)만.** 출격 도중에는 안 바뀐다 —
  그리던 도형이 중간에 깨지면 모방도 점령도 망가진다.
```js
const SIT_EMA = 0.35;   // 새 값을 이만큼씩만 반영 (급변 금지)
```

### 1. 위협도 `sitT` (0~1)
| 신호 | 가중 |
| --- | --- |
| 내 궤적에 가장 가까운 상대까지 거리 < **30칸** | `(1 − 거리/30) × 0.6` |
| 그 거리가 **좁혀지고 있다**(직전 측정보다 가까워짐, 45칸 안) | 한 명당 0.15, 최대 0.25 |
| **최근 날 죽인 상대**가 50칸 안에 있다 | 0.20 |

`lastKiller` 는 `kill()` 에서 기록한다.

### 2. 기회 `sitO` (0~1)
| 신호 | 가중 | 뜻 |
| --- | --- | --- |
| 상대 둘이 **25칸 안**에 붙어 있고 한쪽 궤적이 8칸 넘음 | 쌍마다 +0.25 | 서로 교전 중 — 그 틈에 지른다 |
| 상대가 자기 집에서 **60칸 넘게** 나가 있음 | +0.30 | 그 영역이 비었다 → **그 집 방향으로 감싼다** |
| 남은 시간 1/3 미만 + 내 점유 6% 미만 | +0.35 | 뒤처졌다 — 리스크를 진다 |
| 남은 시간 1/3 미만 + 내가 1위 | **−0.45** | 지킨다 |

빈 땅이 많은 쪽은 `emptyDir()` 이 4칸 간격으로 훑어 찾는다(출격당 한 번).
기회가 0.35 넘고 '집 비운 상대'가 있으면 그쪽, 0.25 넘으면 빈 땅 쪽을 `pickDir` 에서
`span × 0.15` 만큼 가산한다.

### 3. 출격 하나를 어떻게 바꾸나
```js
grow      = clamp(0, 1.2, (1 − 위협) × 0.6 + 기회 × 0.6)
크기       = size     × (0.60 + grow × 1.0)      // ×0.60 ~ ×1.80
복귀 문턱   = maxTrail × (0.50 + grow × 1.0)      // ×0.50 ~ ×1.70
복귀 민감도 = flee     × (1 + 위협 × 0.8)         // 위협이 높으면 빨리 돌아온다
```
그리고 **위협이 높은 국면(`sitT > 0.5`)에서는 무적을 아껴 둔다** — 평소엔
`threat < flee × 1.4` 에 쓰지만, 그땐 `threat < flee` 로 **정말 붙었을 때만** 쓴다.

## B. 사람 스타일 모방 (요약 — 앞 작업 그대로)
사람만 관찰해 궤적 길이·꺾기·직진 구간·면적·출격 거리·사냥 비율·달리기 비율·
아이템 보유 시간·선호 회전 방향을 누적 평균으로 쌓고(`localStorage`, 요약값만),
학습형 봇의 `size·maxTrail·aggr·item·flee·sprint` 와 **도형(꺾는 횟수·변 길이)** 에 쓴다.
표본이 `PROF_MIN=3` 에 못 미치면 **만능 기본값**으로 간다 (첫 판·시크릿 모드).

**A 와 B 는 역할이 다르다.** B 가 "어떤 모양으로" 를 정하고, A 가 "그걸 얼마나 크게" 를 정한다.
`mimicShape()` 는 `size` 를 안 쓰고 사람의 직진 길이·꺾기 횟수를 그대로 쓰므로,
A 가 크기를 조절해도 **모양은 안 망가진다.**

## C. 공통

## 검증

> **대본대로 걷는 가짜 사람**이다. 관찰·판단·모방 경로는 게임 코드 그대로 타지만

## 감독 확인 요청 / 남은 이슈
1. **직접 붙어서 체감이 맞는지 봐 주시기 바란다.** 가만히 두면 크게 돌고, 꼬리를 노리면
   짧게 끊고 자주 들어온다. 수치로는 나오는데 **눈으로 그렇게 느껴지는지**가 중요하다.
2. **성장 폭 `×0.60~1.80` 이 과한지.** 아무도 안 건드리면 다른 봇보다 27% 크게 돈다.
   너무 세면 `adaptPlan` 의 계수 둘만 줄이면 된다.
3. **위협도가 실제 경기에서 0.13 까지만 올랐다.** 사람이 집요하게 쫓으면 더 오를 테지만
   확인은 못 했다. 너무 둔하면 `SIT_NEAR`(30칸)를 넓히면 된다.
4. 25-c B 의 남은 건(`hunt` 실플레이 미검증, `PROF_MIN=3`, 사람별 프로파일 분리)은 그대로다.
5. 26 의 64칸 문턱, 26-b 의 재접속 복귀도 그대로다.
