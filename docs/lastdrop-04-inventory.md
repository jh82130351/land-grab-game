# lastdrop-04 - 인벤토리 + 탄 종류

## 무엇을 했나
예비탄을 총 종류별 공용 주머니(`mags`)에서 **가방 안 탄 종류별**로 바꾸고(장전 탄은 지금처럼 총마다 따로),
Tab 인벤토리(주변·가방·장비), 무게·가방 용량, 버리기, 총 교체 시 바닥에 떨어뜨리기, 봇 사망 상자를 넣었다. 봇은 이번에도 탄 무한.

## 변경 파일 목록
- `lastdrop/game.js`
- `lastdrop/index.html` — 인벤토리 화면(#inv), 조작 안내
- `docs/lastdrop-04-inventory.md`

## 1. 탄 종류 (`AMMO`, `GUNS[].am`)

| 총 | 탄 | 탄창 | 비고 |
|---|---|---|---|
| 권총 | 9mm | **15** (전 12) | 가방 9mm 를 SMG 와 같이 쓴다 |
| SMG | 9mm | 30 | |
| 소총 | 5.56mm | 30 | |
| 샷건 | 12게이지 | **5** (전 6) | |
| 저격 | 7.62mm | 5 | |

| 탄 전리품 | 한 개에 든 양 | 한 발 무게 | 스폰 비율 |
|---|---|---|---|
| 9mm | 30 | 0.5 | 2/5 (권총·SMG) |
| 5.56mm | 30 | 0.5 | 1/5 |
| 12게이지 | 10 | 1.25 | 1/5 |
| 7.62mm | 15 | 0.5 | 1/5 |

- 탄 전리품은 한 종류만 든다 — 전엔 한 번에 모든 총 예비탄이 찼다. 스폰 비율은 총 비율(5종 균등)을 따른다.
- 총은 **탄창 1개분 장전된 채로** 나오고 예비탄은 안 딸려 온다 (전엔 탄창 1개분이 예비로 붙었다).
- HUD: `24 / 5.56mm 90` (장전 / 가방의 그 총 탄). 재장전은 가방의 그 탄에서만 빠진다.
- 탄창 크기는 봇도 같은 표를 쓰므로 봇 권총·샷건도 15·5발이다 (봇은 재장전하면 다시 가득).

## 2. 무게 · 가방 용량

| 가방 | 용량 |
|---|---|
| 없음 | 150 |
| Lv1 | 200 |
| Lv2 | 250 |
| Lv3 | 300 |

| 물건 | 무게 |
|---|---|
| 9mm · 5.56 · 7.62 한 발 | 0.5 |
| 12게이지 한 발 | 1.25 |
| 붕대 | 2 |
| 구급상자 | 10 |
| 구급킷 | 20 |
| 에너지드링크 | 4 |

- 총·방어구·가방은 장비라 무게에 안 들어간다.
- 초과 시: 탄·회복템은 **들어가는 만큼만** 줍고 나머지는 바닥에 남긴다. 하나도 안 들어가면 못 줍고 이유 표시("가방이 가득 찼다 (150/150)").
- 예전의 회복템 개수 상한(붕대 8 등)은 무게로 대체해 없앴다.
- 가방은 전리품으로 나온다(스폰 6%, Lv1~3 균등). 방어구 스폰은 10% → 8% 씩으로 조금 줄였다.
- 가방을 벗으면 150 을 넘는 경우엔 못 벗는다(이유 표시).

## 3. 장비 칸 · 단축키

| 칸 | 단축키 | 들어가는 것 |
|---|---|---|
| 주무기 1 | 1 | 권총 외 |
| 주무기 2 | 2 | 권총 외 |
| 권총 | 3 | 권총만 |
| 헬멧 · 방탄복 · 가방 | — | 더 좋은 것을 주우면 바꿔 끼고 헌 것은 발밑에 |

- **단축키 변경**: 예전 3·4·5·6 = 붕대·구급상자·구급킷·드링크 → **3 = 권총**, 4~6 없음. 회복은 **F(자동)** 와 **인벤토리에서 클릭**.
- 총 교체: 칸이 차 있으면 들고 있던 총(손에 든 주무기, 권총이면 권총 칸)이 **장전 탄째로** 발밑에 떨어진다.
- 보급 상자: 저격(5발 장전) + 7.62 15발 + 구급킷 + 3레벨 헬멧·방탄복. 가방에 안 들어가는 건 발밑에.

## 4. 인벤토리 (Tab)
- 열면 마우스 잠금을 풀고 **게임은 계속 진행**(맞고, 자기장 피해 받고, WASD 로 걷는다). 닫으면 다시 잠근다. Esc 로도 닫힌다.
- 왼쪽 **주변 3m**(봇 상자는 이름 아래 내용물을 펼쳐 보임) · 가운데 **가방**(탄·회복템, 무게) · 오른쪽 **장비**.
- 클릭: 주변 = 줍기, 가방 회복템 = 사용, 장비 총 = 손에 들기. E 줍기도 그대로(상자 앞 E = 인벤토리 열기).
- 우클릭: 버리기 → 발밑에 전리품으로. 탄·회복템은 메뉴로 **전부 / 절반**.
- 봇이 죽으면 그 자리에 **"봇 N 상자"** — 그 봇의 총(남은 장전 탄째) · 그 총 탄 탄창 2개분 · 남은 회복템. 다 꺼내면 사라진다.
- 목록은 `innerHTML` 없이 `createElement`/`textContent` 로 만든다. 열려 있는 동안 0.25초마다 다시 그린다.
- 바닥에 새로 생기는 전리품(버린 물건·상자)을 위해 전리품 메쉬에 여유 칸 400 을 두고, 차면 이미 주운 칸을 다시 쓴다.

## 감독 확인 요청 사항 / 남은 이슈
- 실브라우저(정현): Tab 열고 닫을 때 마우스 재잠금 — 브라우저가 키 입력으로 다시 잠그는 걸 거부하면 '클릭해서 재개' 안내가 뜬다. 헤드리스는 포인터 락을 못 잰다.
- 탄 전리품이 한 종류만 들어 탄이 전보다 귀하다. 탄 스폰 비중(22%)을 올릴지 체감 후 결정.
- 봇은 탄 무한 그대로 — 상자의 탄은 "탄창 2개분" 으로 정했다.
- 봇 상자에는 봇의 헬멧·방탄복은 넣지 않았다(지시서: 총·탄·회복템). 넣을지 결정.
- 내가 죽었을 때 상자는 만들지 않는다(혼자 하는 게임이라).
