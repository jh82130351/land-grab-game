# 19-b - 스킬 수치·효과 확정

## 확정된 값

| 스킬 | 지속 | 효과 |
| --- | --- | --- |
| **속도 부스트** | **5초** | 속도 ×2 — **달리기 11 → 22 m/s** (걷기 6 → 12). **판정은 그대로 빡빡하다** |
| **궤적 무적** | **10초** | 상대가 내 궤적을 밟아도 **안 끊긴다**. 내 궤적을 밟아도 **자멸하지 않는다**. 포위당해도 안 죽는다. **단 내 땅은 그대로 뺏긴다** |
| **점령 확대** | **10초** | 그 동안의 **모든 점령**에 테두리 **2겹**이 붙는다 (전 1겹, 1회용) |
| **순간 귀환** | 즉시 | 그리던 궤적을 점령 처리하고 자기 영역으로 복귀 |

```js
SKILLS[1].sec = 5;   SKILLS[2].sec = 10;   SKILLS[3].sec = 10;
const BOOST_MUL  = 2;   // 달리기 11 → 22 m/s (걷기 6 → 12)
const WIDE_RINGS = 2;   // 테두리 겹 수
```

### 판단이 들어간 두 곳
1. **부스터를 배수로 넣었다.** 지시가 "속도 22 (달리기 11의 2배)"라 **×2**로 잡았다.
   달릴 때 정확히 22 m/s가 되고 걸을 때는 12 m/s다. **걷기·달리기 구분이 살아 있다.**
   걷든 달리든 무조건 22로 고정하려면 `spdMul`을 절대값으로 바꾸면 되는데, 그러면
   걷기가 사라져서 조작이 거칠어진다고 봐 배수로 뒀다.
2. **"내 영역 점령은 그대로 허용"을 이렇게 풀었다.** 무적 상대를 포위하면
   **땅(`owner`)은 가져가되 궤적(`trail`)은 건드리지 않고 그 사람도 안 죽인다.**
   무적은 "안 죽는다"이지 "땅을 지킨다"가 아니라고 읽었다.

## 점령 확대가 시간제로 바뀌었다
전에는 **다음 점령 한 번에만** 붙는 1회용 표식이었다. 이제 **10초 동안 하는 점령마다**
붙는다. 그래서 HUD에도 `다음 점령` 대신 **남은 시간**이 뜬다.

두 겹은 한 겹을 두른 뒤 **그 겹을 다시 바깥으로 밀어** 만든다.

## HUD
슬롯은 그대로 아이콘·이름을 보여 주고, 아래 활성 효과 줄에 **세 효과 전부 남은 시간**이 뜬다.
```
5.0초  속도 부스트
10.0초 궤적 무적
10.0초 점령 확대
```

## 봇과 온라인
- **봇도 같은 규칙**을 그대로 쓴다. 별도 분기가 없다. 확대가 도는 중이면 또 안 쓰도록만 고쳤다.
- **온라인**: 방장이 남은 시간을 계산해 스냅샷에 싣고 게스트는 받아 그린다.
  확대도 0/1이 아니라 **남은 시간(0.1초 단위)**으로 실린다.

## 검증 — 20항목 전부 통과

### 지속시간
```
통과  부스터 5초로 걸린다 / 무적 10초로 걸린다 / 점령 확대 10초로 걸린다
통과  부스터가 정확히 5초 뒤 풀린다
통과  무적이 정확히 10초 뒤 풀린다
통과  확대가 정확히 10초 뒤 풀린다
```

### 부스터 속도와 판정
```
통과  평소 배수 1 · 부스터 배수 2 (달리기 11 → 22)
통과  달리기 속도가 22 m/s
통과  부스터 중에도 옛 궤적을 밟으면 죽는다     ← 판정 관대화 없음
```
실제 브라우저에서 달리기 키를 누른 채 1초 이동거리를 쟀다.
```
평소 달리기      10.4 m/s
부스터 중 달리기  21.4 m/s
```
> 11·22가 아니라 10.4·21.4인 건 **가속이 붙는 데 시간이 걸리기 때문**이다.
> 1초 평균이라 그렇고, 최고 속도 자체는 11·22가 맞다.

### 무적
```
통과  상대가 밟아도 안 죽는다 / 내 궤적도 그대로 남는다
통과  무적 중에는 옛 궤적을 가로질러도 안 죽는다
통과  무적이 없으면 같은 경로에서 죽는다            ← 대조군
통과  무적이면 포위당해도 안 죽는다
통과  내 땅은 뺏긴다 (25칸 → 0칸)                 ← 점령은 그대로 허용
```

## 알려진 이슈
1. **무적이 꽤 강해졌다.** 10초 동안 어떤 이유로도 안 죽는다. 크게 두르고 싶을 때
   쓰면 사실상 공짜로 한 바퀴를 돌 수 있다. 밸런스를 보셔야 할 지점이다.
2. **무적 상대를 포위하면 그 칸이 '남의 땅 + 내 궤적'이 된다.** 표현은 궤적이 위로 보인다.
   그 사람이 나중에 점령하면 그 땅을 도로 가져간다.
3. **부스터 중에도 자멸 판정은 그대로**라, 22 m/s로 달리면 옛 궤적에 걸리기 훨씬 쉽다.
   지시하신 "판정 관대화 없음"을 그대로 따른 결과다.
4. 14·16·23 문서의 판단 대기 건은 그대로다.

## 감독 확인 요청
1. **부스터를 배수(×2)로 잡은 게 맞는지.** 걷기도 12 m/s가 된다.
   걷든 달리든 22로 고정하길 원하시면 한 줄이면 된다.
2. **무적 10초가 너무 센 건 아닌지** (알려진 이슈 1번).
3. **점령 확대가 10초 동안 여러 번 붙는 게 맞는지.** 한 번만 붙이려면 되돌릴 수 있다.
