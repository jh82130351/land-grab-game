# lastdrop-09 - 투척류: 수류탄 · 섬광탄

## 무엇을 했나
- 핫바에 꽂아 드는 투척류 두 가지를 넣었다(가방 무게 수류탄 18 · 섬광탄 15). 조준점·궤적선·낙하지점 표시는 없다.
  - 왼쪽을 꾹 누른 시간 0~1.5초 → 8~28m/s로 던진다. 화면 아래엔 세기 막대만 나오고, 충전 중 오른쪽 클릭은 취소다.
  - 포물선으로 날아가 반발 0.35로 튕기고, 굴러가다 멈춘다.
- 수류탄: 4초 뒤 반경 8m 피해(가운데 120 → 0, 방탄복 적용, 벽·지붕에 막히면 0).
- 섬광탄: 2초 뒤 반경 10m, 사이에 벽이 없을 때만. 흰 덮개·귀 먹먹·삐 소리가 나고, 봇도 시야 0에 무작위로 움직인다.
- 세 맵 모두 전리품에서 나온다. 어려움 이상 봇은 엄폐한 적에게 수류탄을, 방 진입 전에 섬광탄을 던진다. 수영 중엔 던질 수 없다.

## 수치표

| 항목 | 수류탄 | 섬광탄 |
|---|---|---|
| 가방 무게 (한 개) | 18 | 15 |
| 터지는 때 | 손에서 놓은 뒤 **4초** | **2초** |
| 반경 | 8m | 10m |
| 효과 | 피해 = 120 × (1 − 거리/8). 방탄복 적용(몸통 부위로 `hurt`, 헬멧은 안 깎는다). 몸 가운데(발 위 1.0m)까지 광선이 벽·지붕·땅에 막히면 0 | 세기 = 10 × (1 − 거리/10). 흰 덮개 불투명도 = 세기/10, 지속 = 세기(초), 끝 1.5초 동안 서서히 걷힘. 눈까지 광선이 막히면 0. **방향 무관** |
| 소리·화면 | 폭발음(`sBoom`)·불꽃. 22m 안이면 화면 흔들림(가까울수록 크게) | 터지는 소리. 맞은 사람: 저역통과로 소리 먹먹(세기 비례) + 3.6kHz 삐 소리, 섬광 시간 동안 걷힌다 |
| 전리품 | 흔함 (가중치 3) | 보통 (가중치 2) |

| 공통 | 값 |
|---|---|
| 거리 | 터진 곳에서 **몸(발~머리 선분)의 가장 가까운 점**까지. 발밑에서 터지면 0m (그래서 0m = 120 · 10초) |
| 던지기 | 왼쪽 꾹 0~1.5초 → 8~28m/s (선형, 1.5초 넘으면 최대), 바라보는 방향, 눈 앞 0.5m 에서 |
| 표시 | 조준점 숨김(투척류를 든 동안). 궤적·낙하지점 없음. 화면 아래 세기 막대(폭 160px)만 |
| 취소 | 충전 중 오른쪽 클릭. 무기를 바꾸거나 물에 들어가도 취소 |
| 물리 | 중력 14m/s², 한 프레임 4번 나눠 계산. 상자(지난 자리가 바깥이던 축의 면)·지형(경사 법선)에 튕긴다 — 법선 성분 반발 0.35, 접선 성분 마찰 0.8(바닥)·0.9(벽). 바닥에선 굴러가다 0.3m/s 아래면 멈춘다. 물속은 느려진다 |
| 전리품 | 전리품 자리의 11% 를 투척류로 바꾼다. 수류탄 60% : 섬광탄 40%, 한 곳에 1~2개. 실측: 초원 46 · 사막 24 · 산지 111 곳 |
| 줍기 | 가방 무게 안에서만. 처음 줍는 종류면 빈 핫바 칸에 자동으로 꽂는다(나만). Tab 가방 줄을 클릭하면 핫바로, 우클릭 메뉴로 핫바 n번 · 버리기. 죽으면 상자에 들어간다 |
| 수영 중 | 충전이 시작되지 않는다("수영 중 — 던질 수 없다"). 물에 들어가면 충전 취소 |
| 1인칭 | 손에 작은 모형(수류탄 = 녹색 구 + 레버, 섬광탄 = 회색 원통) |

## 감독 확인 요청 사항 / 남은 이슈
1. **거리 재는 법**: 터진 곳 → 몸(발~머리) 가장 가까운 점이다. 눈이나 몸 가운데로 재면 바닥에서 터진 0m 가 1.3m 쯤이 되어 "0m = 10초 / 120" 이 안 나온다. 벽 판정 광선은 몸 가운데(수류탄)·눈(섬광)으로 쏜다.
2. **수류탄 방탄복**: 몸통 부위로 넣어 방탄복만 깎인다(헬멧 안 깎음). 머리 판정은 없다.
3. **어려움 이상 봇 비율**이 낮아(6.5%) 보통 판에선 봇 투척이 거의 없다. 실전 투척은 "모든 봇 어려움" 판으로 확인했다.
4. 봇은 날아오는 수류탄을 피하지 않는다(사양에 없음).
5. 수류탄은 지프에도 같은 공식으로 피해를 준다(벽에 막히면 0).
