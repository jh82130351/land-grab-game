# 30-c 판 길이 규칙 최종 (단순화)

정현 지시 "[수정 - 판 길이 규칙 최종 (단순화)]" 반영. 2026-10-31 운영 배포.

## 규칙

판 길이 = 매치 토큰 발급(수송기 출발) ~ 결과 제출(사망 또는 1등). **서버가 토큰 발급 시각으로 잰다.**

| 판 길이 | 기록 | 코인 |
|---|---|---|
| 30초 미만 | 안 함 (status `short`) | 없음 — 결과 화면 "30초 미만 판은 기록되지 않습니다" |
| 30초 이상 | 저장 | 1등 10 / 2등 3 / 3등 2 / 4등 1 / 5등 이하 0 |

- 없앤 것: 1등 4분·2~4등 3분(이전 `MIN_MATCH=180`, `too_short` 거부), 4등 안 생존 150초 검사(`bad_survival` 의 그 부분).
- 그대로: 토큰 1회 사용(`token_reused`), 시간당 12판(13번째 `hourly_cap` 거부) — **30초 미만 판도 횟수에 들어간다.**
  생존시간 ≤ 경과시간+5, 킬·명중 상한 검사도 그대로.
- `short` 행은 시간당 판 수 세기에만 쓰이고, 1시간 지난 것은 다음 짧은 판 때 지운다. 전적(`RECORDED`)에는 안 들어간다.
