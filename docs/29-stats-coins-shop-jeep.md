# 29 - 전적 · 코인 · 상점 · 자유 색 · 지프 파괴

## 무엇을 했나
라스트 드롭에 계정별 **전적**(홈 [기록], 상단 "치킨 N회 · 승률 N%")과 **코인**(순위 보상, 서버 계산·매치 토큰 검증),
코인으로 사는 **상점 장식 10종**(머리·얼굴·등), **무료 자유 색**(피부·머리·옷·가방), 게임 안 **지프 파괴**(체력·잔해·폭발)를 넣었다.
운영 계정 모듈이 바뀌어 **Flask 재기동 1회 — 순단 약 0.9초**.

## 3. 자유 색 (무료)
피부 · 머리 색 · 상의 · 하의 · 가방 — 빠른 칸 8색 + **자유 색 선택기**(`<input type="color">`). 코인 불필요. 머리 모양 3종도 무료.
저장 형식 v2 `{v:2, hair, skin, hairColor, top, bottom, bag, head, face, back}` (색은 `#rrggbb`). 예전 v1(프리셋 번호)은 불러올 때 v2 로 바꾼다.

## 4. 위조 방지 (최소) — 서버에서만 계산

| 항목 | 구현 |
|---|---|
| 일회용 매치 토큰 | 판 시작 `POST /game/api/lastdrop/match/start` (CSRF) → 랜덤 토큰, DB 엔 sha256 만 |
| 토큰 1회 사용 | 결과를 내면 상태가 바뀐다 — 다시 내면 `token_reused` 거부 |
| 판 길이 최소 3분 | **서버가 잰** 토큰 발급 → 결과 제출 시간. 3분 미만에 **4등 안이면 거부**(`too_short`). 3분 미만 5등 이하는 전적만(어차피 코인 0 — 일찍 죽은 판도 판수에 들어가게) |
| 계정당 시간당 최대 12판 | 지난 1시간에 코인 받은 판이 12 이상이면 그 판은 전적만, 코인 0 (`hourly_cap`, 로그) |
| 순위·킬 범위 | 순위 1~16 정수, 킬 0 ~ (16 − 순위) (내 아래 순위 = 먼저 죽은 사람 수), 발사 0~20000, 명중 ≤ 발사, 생존시간 ≤ 서버 경과시간 + 5초 |
| 토큰 만료 | 발급 1시간 뒤 |
| 토큰 남용 | 계정당 시간당 발급 40개 |
| 실패 시 | 지급 거부 + `rejects` 테이블 + Flask 로그 `[game_accounts] 매치 결과 거부 user=… reason=…` |
| 코인 잔액 | `wallet` (서버). 지급·구매는 `coin_log` 에도. 클라이언트가 보낸 코인·가격은 받지 않는다 |
| 구매 | `UPDATE wallet SET coins = coins - 가격 WHERE coins >= 가격` + 보유 등록을 한 트랜잭션. 중복은 PK + 사전 검사 409 |
| 장착 | 서버가 "그 부위의 상품이고 보유한 것" 만 받는다 |

> 이 정도로는 결과값 자체(순위 1등)를 거짓으로 내는 걸 막지 못한다 — 오프라인 게임이라 서버가 판을 모른다. 범위·시간·횟수로 이득을 시간당 120 코인 안쪽으로 묶는 수준. 온라인 대전이 되면 서버가 결과를 정한다.

## 6. 지프 파괴 — 수치

| 항목 | 값 |
|---|---|
| 지프 체력 | **400** (HUD: 탑승 중 `지프 N/400`) |
| 피격 판정 | 사람보다 먼저 차체 — 회전된 상자(반폭 1.15 · 반높이 0.82 · 반길이 2.2, 중심 높이 1.13 → 바닥 0.31 ~ 1.95, 탑승자 머리까지) |
| 차체 피해 | 그 총의 기본 피해 × 거리 배율 (부위 배율 없음) |
| 멀쩡한 동안 탑승자 | 총·주먹에 안 맞는다 (차체가 막음) |
| 맞을 때 | 금속 소리(70m 안) · 불꽃 |
| 파괴 (0) | 불타는 잔해(검게 · 불꽃 5개 일렁임), 못 움직이고 못 탄다, **엄폐물**(이동·총알을 막는 상자) |
| 탑승자 | 강제 하차(옆 2.6m) + **피해 30** (파괴한 사람에게 킬 판정), 이후엔 보통처럼 맞음 |
| 폭발 | 파괴 **2.5초** 뒤, 반경 **6m**, 피해 **60 × (1 − 거리/6)** (가까울수록 큼), 사이에 벽이 있으면 막힘 |
| 봇 | 어려움 이상은 지프에 탄 나를 보면 **지프 중심**을 노린다 (그 아래 단계도 나를 노리지만 차체에 막힌다) |

## 7. 검증

## 감독 확인 요청 사항 / 남은 이슈
1. **가격·코인표 조정 (정현)** — 1등 10 코인이면 왕관(100)까지 치킨 10번.
2. **무료 모자 정리** — 캡·비니가 상품이 되며 예전 무료 모자 항목을 뺐다. 헬멧형을 무료로 남길지.
3. **스카프를 '등' 부위로** 넣었다(3부위 제한) — 망토와 같이 못 쓴다.
4. 3분 규칙을 "4등 안이면 거부, 5등 이하는 전적만" 으로 했다 — 지시서는 "3분 미만 판 거부".
5. 위조 방지는 최소 수준(위 4절 마지막 줄) — 오프라인 게임의 한계.
6. 잔해는 판 끝까지 남는다(불꽃 포함). 봇은 지프를 타지 않는다.
7. 실브라우저(정현): 상점 확인 클릭, 자유 색 선택기, 지프 금속음·폭발 체감.
