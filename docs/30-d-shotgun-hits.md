# 30-d 샷건 명중 집계로 1등 판이 거부됨 (긴급)

카드 "[버그 - 샷건 명중 집계로 1등 판이 거부됨 (긴급)]" 기록. 2026-10-31 운영 배포 (커밋 `6e6949e`).

## 원인

1. **명중 집계** — `fireFrom` 이 `hits++` 를 산탄 알갱이마다(샷건 1발에 최대 8), `shots++` 는 방아쇠 1번에 1.
   → 샷건을 맞히면 hits > shots → 서버 `_int(hits, 0, shots)` 실패 → 판 전체 거부(`bad_shots`).
2. **발사 수 누락** — 사격은 "프레임마다 왼버튼이 눌려 있으면 쏜다" 였다.
   - 두 프레임 사이에 눌렀다 뗀 짧은 클릭은 **아예 안 쏜다** (발사 0, 집계도 0).
   - 쿨다운(샷건 0.85초 · 저격 1.45초) 중에 누르고 쿨다운 전에 뗀 클릭도 사라진다.
   → 정현이 "8번보다 많이 쐈다" 고 한 것과 맞는다. 집계가 빠진 게 아니라 **총이 실제로 안 나갔다**.

## 고친 것

| | 전 | 후 |
|---|---|---|
| 클라이언트 명중 | 알갱이마다 +1 | **방아쇠 1번에 1알이라도 피해를 줬으면 +1** (샷건 포함, 항상 hits ≤ shots) |
| 클라이언트 클릭 | 프레임에 눌려 있을 때만 | **0.3초 클릭 버퍼** — 톡 친 클릭은 다음 프레임에, 쿨다운이 0.3초 안 남았을 때 누른 클릭은 쿨다운 끝나자마자 쏜다 |
| 서버 발사·명중 이상 | 판 거부 `bad_shots` | **판은 정상 기록·코인, 그 판 명중 통계만 0/0** + 로그 `shots_voided` (rejects 표) |
| 서버 판 거부 | — | 토큰(모름·재사용·만료) · 시간(생존 > 경과+5, 30초 미만은 기록 안 함) · 순위 범위 · 킬 범위 · 시간당 12판에만 |

- 탄 0 클릭 = 재장전 시작(발사 아님), 재장전 중 클릭 = 발사 아님 — 총이 안 나가니 그대로가 맞다.

## 검증

### 총 종류별 방아쇠 (헤드리스, 실제 mousedown/mouseup 이벤트)

| 무기 | 톡 친 클릭 10번 → 발사 | 쏘고 + 쿨다운 0.15초 전 클릭 ×10 → 발사 (기대 20) |
|---|---|---|
| 권총 · SMG · 소총 · 샷건 · 저격 · 주먹 | 전부 **10** | 전부 **20** |

- 같은 시험을 전 코드에: 프레임 사이 클릭 → 6종 전부 **발사 0**. 3프레임 누른 클릭 → 톡 10번은 10, 일찍 누른 클릭은 **20 중 10**(쿨다운 중 클릭이 사라짐).
- 핫바 교체(권총↔샷건) 직후 클릭 10번 → 발사 10.
- 탄 0 클릭 → 발사 0 · 재장전 시작, 재장전 중 클릭 5번 → 발사 0, 재장전 뒤 클릭 → 발사 1.
- **샷건 3m 10발**: 전 코드 발사 10 · 명중 **80 (800%)** → 후 발사 10 · 명중 **10 (100%)**.
