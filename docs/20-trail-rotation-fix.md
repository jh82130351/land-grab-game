# 20 - 궤적 블록이 제자리에서 돌던 버그

## 증상 (정현 보고)
> 궤적(트레일) 블록들이 제자리에서 돌아간다. 가만히 고정돼 있어야 함.

## 원인 — 임시 객체 하나를 궤적과 아이템이 같이 썼다

궤적 블록도 스킬 아이템도 `InstancedMesh`라, 인스턴스마다 행렬을 만들어 넣는다.
그 행렬을 만드는 데 쓰는 임시 객체 `dummy`가 **하나뿐이었다.**

```js
const dummy = new THREE.Object3D();

function syncTrailMesh() {              // 궤적 — 위치만 쓴다
  dummy.position.set(wxOf(gx), 0.45, wzOf(gz));
  dummy.updateMatrix();                 // ← 회전은 안 건드린다 = 직전 값이 그대로 남아 있다
  mesh.setMatrixAt(n, dummy.matrix);
}

function syncItems(now) {               // 아이템 — 돌아야 해서 회전을 건다
  dummy.rotation.set(0, now / 700 + o.i, 0.5);
  dummy.updateMatrix();
}
```

**19단계에서 도는 아이템을 넣으면서 같은 `dummy`에 회전을 걸었다.**
`syncTrailMesh()`는 회전을 0으로 되돌리지 않으므로, 아이템이 남겨 둔 회전이
**그대로 모든 궤적 블록에 묻는다.**

각도는 `now / 700`이라 매 프레임 달라지고, 궤적은 누가 움직일 때마다 다시 채워지므로
**궤적 전체가 프레임마다 다른 각도로 틀어진다.** 그게 "제자리에서 돈다"의 정체다.

### 영역(점령 셀)은 문제가 없었다
점령지는 메시가 아니라 **바닥 평면에 입힌 텍스처**(`DataTexture`)다. `paint()`는 픽셀만
칠하고, 바닥 평면은 만들 때 한 번 눕힌 뒤로 건드리지 않는다. 참가자 몸체도 위치만 옮긴다.

파일 전체에서 회전을 건드리는 곳을 훑은 결과, **매 프레임 도는 건 스킬 아이템 하나뿐**이고
나머지(바닥·벽·천장)는 전부 만들 때 한 번 돌려 두는 것이었다.

## 고친 내용

**도는 것과 안 도는 것의 임시 객체를 나눴다.**
```js
// 인스턴싱용 임시 객체. 회전을 쓰는 쪽과 안 쓰는 쪽을 반드시 나눠 둔다.
// 하나를 같이 쓰면 회전을 건 쪽의 값이 남아 다음 쪽에 묻는다.
const dummy = new THREE.Object3D();     // 격자에 고정되는 것 — 회전 없음
const spin  = new THREE.Object3D();     // 도는 것 (스킬 아이템)
```
`syncItems()`는 `spin`을 쓴다. 그리고 `syncTrailMesh()` 앞에 못을 하나 박았다.
```js
dummy.rotation.set(0, 0, 0);            // 궤적 블록은 격자에 고정 — 절대 돌지 않는다
dummy.scale.set(1, 1, 1);
```
나중에 또 누가 `dummy`에 회전을 걸어도 궤적은 안 돈다.

## 검증

눈으로 보는 대신 **인스턴스 행렬을 직접 뜯어 회전량을 쟀다.**
행렬을 분해해 얻은 쿼터니언은 회전이 없으면 `w = ±1`이다. `|1 - |w||`가 곧 회전량이고,
**0이면 전혀 안 돈다**는 뜻이다.

### (1) 봇전 — 45초 동안 시점을 계속 돌리며 표본 채집
| | 궤적 표본 | **궤적 최대 회전량** | 아이템 최대 회전량 | 오류 |
| --- | --- | --- | --- | --- |
| 고치기 전 (19) | 3,434 | **0.934457** | 0.7727 | 0건 |
| **고친 뒤 (20)** | 3,464 | **0** | 0.9748 | 0건 |

**정확히 0이다.** 아이템은 반대로 여전히 돈다 — 그건 의도한 동작이다.

### (2) 온라인 2인 (실서버 사본 5099 + 실브라우저 2대)
방장과 게스트 양쪽에서 같은 방식으로 쟀다. 시점을 계속 돌리며 40초.
```
방장   궤적 표본 3,690 · 궤적 최대 회전량 0 · 아이템 8개 · 오류 0건
게스트 궤적 표본 3,640 · 궤적 최대 회전량 0 · 아이템 8개 · 오류 0건
```
궤적 메시는 방장이든 게스트든 **격자(`trail` 배열)를 그대로 훑어 만들므로**
같은 코드가 돌고, 양쪽 다 0이다.
