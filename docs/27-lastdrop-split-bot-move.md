# 27 — 라스트 드롭을 다시 따로 두고, 봇이 안 움직이던 문제를 고쳤다

날짜: 2026-10-23
지시: "라스트 드롭이라는 거는 따로 하고 배틀그라운드 다시 살려" / "라스트 드롭에서 몹이 안 움직여, 몹이 움직이게 해줘"

## 1. 주소 정리

| 주소 | 게임 | 원본 |

| `/game/lastdrop/` | 라스트 드롭 (완성품) | 이 레포 `lastdrop/` |
| `/game/br/` | 배틀로얄 01·02 단계 빌드 (단계별 개발) | battle-royale 레포 `br/index.html` |

3c0e2a1(lastdrop 제거)을 되돌렸다. 허브 카드도 둘로 돌아갔다.
battle-royale 5064f0a 의 시작화면 버그 수정(`[hidden]{display:none!important}`, `lockMouse()`)은 lastdrop/ 에 그대로 옮겼다.

## 2. 봇이 안 움직이던 원인 두 가지

1. **전원 착지 전에는 봇 AI 가 아예 안 돌았다.** `updateBot` 은 `matchState === 'live'` 에서만 불렸고,
   live 는 플레이어까지 16명이 다 내려야 시작된다. 봇은 낙하산 9초면 내리는데 플레이어가 늦게 뛰면
   그동안 땅에 박혀 서 있었다. → drop 단계에서도 착지한 봇은 `updateBot` 을 돌린다.
   공중에 있는 사람(drop !== 'ground')은 노리지 않는다.
2. **벽에 막히면 그대로 섰다.** 목표점으로 직선으로만 걸어서 건물 벽·모서리에 끼었고,
   벽 속에 착지한 봇은 어느 쪽으로도 못 나왔다. → 0.4초 동안 기대 거리의 30% 도 못 가면
   `botDetour()` 가 옆 방향(±45°·±90°·±135°·뒤)을 1.5m 앞까지 재 보고 빈 쪽으로 0.7~1.6초 돌아간다.
   벽 속이면 먼저 반경 3m 안 빈 자리로 빼 준다.

## 3. 검증 (헤드리스 크롬, 실제 게임 루프)

- 수정 전(실서버): 착지한 봇 15기 전원 5초 이동 0.0m (state=drop 동안).
- 수정 후: 착지 직후부터 이동, live 에서도 계속 이동.
- 벽 끼임: 수정 전 2판에서 5기 멈춤 → 수정 후 3판(착지 봇 41기) 멈춤 0기.
