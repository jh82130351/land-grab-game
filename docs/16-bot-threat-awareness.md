# 16 - 봇 위협 인식 보완 (영역 안 상대를 무시하다 꼬리 잘림)

## 증상 (정현 보고)
> 플레이어가 자기 점령지 안에 있으면 봇이 위협으로 인식 못 하고 그쪽으로 접근 →
> 플레이어가 나와서 봇의 궤적(꼬리)을 끊어버릴 수 있다.

## 원인 — 두 가지가 겹쳤다

**하나. 봇이 남의 땅 쪽으로 일부러 나갔다.** `pickDir()`이 방향을 고를 때 이렇게 점수를 줬다.
```js
else if (owner[i] !== b.id) s += 0.9;     // 남의 땅 — 뺏으면 이득이 크다
```
땅 주인이 그 위에 서 있다는 사실은 점수에 전혀 안 들어갔다. **주인이 집을 지키고 있는
쪽일수록 그 땅은 비어 있고, 그래서 봇에게는 제일 매력적으로 보였다.**

**둘. 위협을 '지금 거리'로만 쟀다.** `threatToTrail()`은 적의 현재 위치까지의 거리만 본다.
제 땅에 가만히 선 상대는 멀찍이 떨어진 것으로 계산되니, 봇은 그 코앞까지 꼬리를 늘어놓고도
위험 신호를 못 받았다. 사람이 한 걸음 나오면 그걸로 끝이다.

### 비대칭이 핵심이다
자기 땅 위에 서 있고 궤적이 없는 상대는 **잃을 게 없다.** 튀어나와 남의 꼬리를 밟아도
자기는 아무 손해가 없고, 실패해도 제자리로 돌아가면 그만이다.
반대로 자기도 궤적을 늘어놓은 상대는 서로 위험해서 함부로 달려들지 못한다.

**"사냥 대상이 아니다"와 "위험하지 않다"는 다르다.** 14단계에서 넣은 사냥 문턱은
제 땅에 있는 상대를 사냥감에서 뺐는데, 그게 위험 계산에서까지 빠지는 부작용을 낳았다.

## 고친 내용

### 1. 위협 인식 분리
```js
// 이 상대는 '지금 잃을 게 없는' 상태인가.
function isSafeFoe(e) {
  if (e.trail.length) return false;                          // 자기도 꼬리가 있으면 위험 부담이 있다
  return owner[gzOf(e.z) * GRID + gxOf(e.x)] === e.id;       // 자기 땅 위에 서 있다
}
```
- **사냥 대상 판정은 그대로다.** 제 땅에 있는 상대는 여전히 사냥감이 아니다 (14 문서 문턱).
- **위험 판정은 따로 간다.** 잃을 게 없는 상대일수록 더 위험하게 친다.

### 2. 출격 사거리 — 가만히 있다고 안전한 게 아니다
```js
const SORTIE = 40;      // 40칸 = 60m. 달리기 11m/s로 5초 남짓이면 닿는다

const bias = isSafeFoe(e) ? SORTIE : 0;
const d = |적 - 내 궤적 칸| - bias;     // 잃을 게 없는 상대는 그만큼 당겨 본다
```
제자리에 서 있어도 **언제든 달려나올 수 있는 거리**만큼 미리 당겨서 위험을 계산한다.
그래서 복귀 전환(`flee`)이 실제로 잘리기 전에 걸린다.

### 3. 궤적 노출 중 회피 — 그쪽으로는 꼬리를 들이밀지 않는다
`pickDir()`에 감점을 넣었다.
```js
const DODGE = 6;        // 출격 사거리 안 한 칸당 최대 감점
for (const [fx, fz, r] of foes) {
  const fd = |후보칸 - 적|;
  if (fd < r) s -= (1 - fd / r) * DODGE;      // 가까울수록 크게 깎는다
}
```
- 잃을 게 없는 상대는 반경 **40칸**, 자기도 노출된 상대는 그 절반인 **20칸**.
- **감점이지 금지가 아니다.** 다른 방향이 더 나쁘면 그쪽으로도 간다. 무조건 피하다
  확장을 멈추는 걸 막는 장치다 (지시 3번).

### 4. 상대가 나오면 즉시 일반 로직
따로 전환 코드가 없다. **상대가 자기 땅을 벗어나거나 궤적을 그리기 시작하면
`isSafeFoe()`가 곧바로 거짓이 되고**, 회피 반경은 절반으로 줄며 14단계의 사냥 판정이
그대로 적용된다. 상태를 들고 있지 않으니 어긋날 일이 없다.

### 5. 자멸 방지
손대지 않았다. 칸을 고르는 마지막 관문은 13단계 그대로다.
```js
if (trail[다음칸] === b.id) continue;
if (guard && routeHome(b, nx, nz) === -1) continue;
```
`pickDir()`은 **가고 싶은 방향의 순서**만 바꿀 뿐 관문을 건너뛰지 않는다.
아래 검증 전체에서 봇 자멸 0회다.

## 검증

### 검증 장치 — 숨어 기다리는 플레이어
증상을 그대로 재현하는 상대를 만들었다. **맵 한가운데 자기 땅에 앉아 있다가,
사거리 30칸 안에 봇 꼬리가 들어오면 달려나가 밟고 돌아온다.**

> 처음에는 플레이어를 원래 자리인 귀퉁이(50,50)에 두고 쟀는데 **증상이 재현되지 않았다.**
> 네 집이 100칸씩 떨어져 있어 봇이 애초에 거기까지 오지 않는다(사거리 안 꼬리 0.2%).
> 봇이 실제로 확장해 오는 한가운데에 앉혀야 이 그림이 나온다.

### (1) 꼬리를 들이대는 일이 줄었는가 — 40판
| | 구버전(15) | **신버전(16)** |
| --- | --- | --- |
| 내가 자른 봇 꼬리 | 127회 (판당 3.2) | **16회 (판당 0.4)** |
| 내 사거리 안에 꼬리가 있던 시간 | 5.7% | **0.8%** |
| 봇 평균 점유율 | 3.92% | **5.90%** |
| 봇 0% 방치 | 36/120 | **10/120** |
| **봇 자멸** | **0회** | **0회** |
| 내가 죽은 횟수 | 147회 | 17회 |

**꼬리를 자를 기회가 8분의 1로 줄었다.** 내가 죽은 횟수까지 줄어든 것은,
잘라 먹을 게 없으니 굳이 튀어나갈 일도 없어졌기 때문이다.

### (2) 과잉 회피가 아닌가 — 일반 봇전 봇3 · 40판
| | 구버전(15) | **신버전(16)** |
| --- | --- | --- |
| 평균 점유율 | 7.49% | **8.58%** |

| 총 사망 | 35회 | **17회** |
| **봇 자멸** | **0회** | **0회** |

**점유율이 오히려 올랐다.** 회피 반경이 봇끼리도 작동해서(서로 20칸) 쓸데없이
부딪혀 죽는 일이 줄었기 때문이다. 확장을 멈추는 징후는 없다.

### (3) 밖으로 나온 사람은 여전히 사냥당하는가 — 미끼 40회
14 문서의 미끼(맵 한가운데를 크게 한 바퀴, 달리기 11m/s)를 그대로 돌렸다.

| | 구버전(15) | **신버전(16)** |
| --- | --- | --- |
| 봇에게 잘림 | 36/40 | **38/40** |
| 잘리기까지 평균 | 40.8초 | 43.6초 |

**숨어 있는 상대만 피하고, 나온 상대는 그대로 쫓는다.** 잡는 데 3초쯤 더 걸리는 건
봇이 확장 중에 거리를 조금 더 두기 때문이고, 잡는 비율은 오히려 올랐다.

### (4) 출격 사거리를 정한 근거 — 각 30판, 감점 6 고정
| `SORTIE` | 자른 꼬리 | 들이댄 시간 | 캠퍼판 봇 점유 | 일반 봇전 | 자멸 |
| --- | --- | --- | --- | --- | --- |
| 0 (끔) | 77회 | 4.8% | 4.41% | 8.23% | 0 |
| 22칸 | 53회 | 3.5% | 5.49% | 7.62% | 0 |

**40칸에서 꺾인다.** 60칸이 수치상 조금 더 낫지만 90m 반경을 통째로 비켜 주는 셈이라,
봇이 사람 근처에 아예 안 오는 그림이 된다. 수치에 안 잡히는 "경기가 심심해지는" 쪽이
걱정돼 40칸으로 잡았다. **올리고 싶으면 상수 하나만 고치면 된다.**

### (5) 실제 브라우저

## 알려진 이슈
1. **온라인 대전에는 적용되지 않는다.** 이건 봇의 판단이고, 온라인에는 봇이 없다.
   사람끼리 붙으면 숨어 기다리다 자르는 수가 그대로 통한다.
   14 문서에서 올린 밸런스 건과 같은 자리다.
2. **회피 반경이 고정값이다.** 상대가 걷는지 달리는지, 얼마나 빨리 반응하는지는 안 본다.
   느리게 움직이는 상대에게도 40칸을 비켜 준다.
3. 사망 페널티 전부 잃음, 치팅 방지 없음, 자동 기동 미적용은 그대로다.

## 감독 확인 요청
1. **직접 집 안에 숨어 기다려 보고, 봇이 예전처럼 코앞에 꼬리를 늘어놓는지.**
   이제는 40칸 밖에서 돌아서 나간다.
2. **봇이 너무 멀찍이 도는 느낌은 아닌지.** 수치상 확장은 늘었지만 체감이 중요하다.
   심심하면 `SORTIE`를 22칸으로 낮추고, 더 확실히 막고 싶으면 60칸으로 올리면 된다.
3. 14 문서의 온라인 밸런스 건(위 알려진 이슈 1번) 방침은 아직 못 받았다.
