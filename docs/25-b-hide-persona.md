# 25-b - 봇 성향을 화면에서 숨김

## 무엇을 했나
순위표에 붙던 **봇 성향 태그(고유 색 + 이름)를 뺐다.** 성향 로직·파라미터·실수는
25 문서 그대로 돌아가고, **어떤 봇이 뭘 노리는지는 움직임으로만 드러난다.**

## 바뀐 곳 — 표시 세 군데뿐
| 위치 | 변경 |
| --- | --- |
| CSS `#score .tag` | 규칙 삭제 |
| `buildScoreRows()` | 태그 `span` 생성·삽입 삭제 → 칸 구성이 `dot + nm + pc` 로 복귀 |
| `drawHud()` 순위표 갱신 | 성향 이름·색을 넣던 네 줄 삭제 |

## 남겨 둔 것 (일부러)
- `PERSONAS`의 `css` 값, `e.persona`, `e.ai.tag`
- **방장 → 게스트 성향 동기화** (`entPayload` 마지막 칸의 성향 번호)

표시를 지웠다고 동기화까지 빼면, 다시 보이게 할 때 온라인에서 방장·게스트가
서로 다른 성향을 그리는 25 문서의 문제가 되돌아온다. 숫자 하나 값이라 비용도 없다.
**다시 켜려면 순위표에 `span` 하나 붙이는 게 전부다.**

## 검증 — 봇3 · 180초 · 20판
### (1) 화면에서 사라졌는가
```
#score .tag span 개수 : 0        (기대 0)
칸 구성  dot+nm+pc   표시 내용 '나'
칸 구성  dot+nm+pc   표시 내용 '봇 A'
칸 구성  dot+nm+pc   표시 내용 '봇 B'
칸 구성  dot+nm+pc   표시 내용 '봇 C'
```
이름만 남고 성향 글자·색이 없다. 빈 칸이 끼어 생기는 간격도 없다 (`span` 자체를 안 만든다).

### (2) 동작은 그대로인가
| 성향 | n | 평균 점유 | 사망/판 | 달림 | 최고 궤적 |
| --- | --- | --- | --- | --- | --- |
| 저격수 | 10 | 7.03% | 0.20 | 36.1% | 209 |
| 만능 | 11 | 6.90% | 0.36 | 28.1% | 201 |
| 확장 | 12 | 6.84% | 0.50 | 29.0% | 215 |
| 수집가 | 7 | 6.84% | 0.29 | 35.5% | 193 |
| 교란 | 10 | 6.50% | 0.20 | 22.9% | 143 |
| 돌격 | 10 | 6.36% | **0.70** | 26.6% | **224** |

```
전체 평균 6.75% · 0% 방치 0/60 · 봇 자멸 0회 · 피살 23회
아이템 213개 · 스킬 168회 (확대 54 · 부스트 41 · 무적 38 · 귀환 35)
실수 145 / 판정 12,920 = 1.122%
```
**자멸 0 유지, 실수 1% 유지, 성향별 차이 유지.**

> 성향 순위가 25 문서의 40판 표와 다르게 나왔는데, 성향당 n이 7~12뿐인 표본 차이다.
> 성향마다 매 판 뽑히는 횟수가 달라 20판으로는 순위가 흔들린다.
> **성향별 수치는 25 문서의 40판 표(개체 120)를 기준으로 보는 게 맞다.**
> 이번 20판은 "표시를 지운 뒤에도 안 깨졌는지"를 보는 회귀 확인이다.
